# Reproducing the figures of the paper

The two case studies in this repository drive **commercial** simulators
(ANSYS Maxwell for Case 1, SolidWorks + MSC Adams for Case 2). The source
code in this release documents the agent workflow, constraints, baselines and
simulator interfaces, and can be adapted to other physical evaluators.

## What is shipped

* The complete agent core (`src/mymcp/`).
* The two case-specific entry points (`case_*/run_optimization.py`)
  and the corresponding MCP servers / tool definitions.
* All baseline wrappers used for the actuator and robot-leg comparisons
  (`case_actuator/baselines/`, `case_robot_leg/baselines/`).

## Source-data package

Processed source data for the manuscript figures are provided with the paper,
separately from this code release. The package is grouped by figure and each
file is named after the panel it supports:

| Folder | Contents |
|---|---|
| `Fig2/` | design-space samples, search trajectories and method-level comparison means for the actuation-system and locomotion-system design problems |
| `Fig3/` | lineage-tree evaluation states, proposal fate map, convergence curves, transfer runs and expert-feedback data |
| `Fig4/` | static-thrust measurements, the frequency-total-current operating map and the literature comparator coordinates |
| `Supplementary/` | ablation, transfer and expert-feedback source tables, and Supplementary Table S19 |

`MANIFEST.csv` in that package maps every file to its panel-level role.
Figure 1, Fig. 4b, 4d, 4e and the schematic or photographic supplementary
figures have no underlying numerical data.

The following local files are outside the scope of the code repository:

| Local file class | Notes |
|---|---|
| Credentials (`.env`, API keys, OpenRouter/OpenAI keys) | User-specific runtime configuration |
| Full local run logs (`AgenticOPT_*.csv`, `*_results_*.csv`, `RobotLeg_*.csv`) | Generated by local optimisation runs |
| Experience folders (`AgenticOPT_*_experience/`, `*_experience/`) | Runtime memory streams generated by the agent |
| Maxwell `.aedt`, `.aedtresults`, `.fld`, `.asol` files | Local FEA projects and solver outputs |
| SolidWorks `.SLDASM`/`.SLDPRT`, Adams templates/results, `package/` | Local CAD/MBD projects and solver package |
| RAG cache (`.rag_cache.json`), feedback storage (`feedback_storage.json`) | Runtime retrieval and feedback storage |
| Rendered PNG/PDF/SVG figures | Outputs generated from the source-data tables |
| `letta/`, `reflexion/`, `ExpeL/`, `generative_agents/`, `baselines/POM/`, `baselines/BOEngineeringBenchmark/` | Third-party projects; obtain from the upstream repositories listed in [`third_party.md`](third_party.md) |

## Extended dataset

Beyond the plotted source data, the following material is archived and available
from the corresponding author on request:

1. Repeated-run trajectories for every optimizer condition, including failed
   proposals and their diagnoses.
2. Fabricated-device measurements behind the actuator and robot-level statistics.
3. Transfer, ablation and expert-feedback run records.
4. Solver templates that can be shared under the relevant software licences.

## Re-executing the agent on a non-commercial simulator

The two MCP tools in `src/mymcp/tool/` (`maxwell.py`, `robot_leg.py`)
are the *only* points where the framework talks to the simulator.  To
plug in your own simulator:

1. Create `src/mymcp/tool/<your_problem>.py` exposing two functions
   with the same signatures as `validate_*` and `run_*`.
2. Register them in `src/mymcp/tool/__init__.py`.
3. Copy `case_actuator/run_optimization.py` to `case_<your_problem>/`,
   update `SERVER_SCRIPT`, the system prompt and the parameter list.

No other module needs to be modified.
